# 📊 Excel Data Cleaning and Quality Report Project

## 📌 Project Overview
This project focuses on data cleaning and data quality assessment using Excel. The goal is to ensure the dataset is clean, consistent, and ready for analysis using standard data preprocessing techniques.

---

## 🧹 Data Cleaning Steps
- Handled missing values  
- Removed duplicate records  
- Fixed inconsistent date formats  
- Standardized text data  

---

## 🧠 Feature Engineering
- Created Age column  
- Created Total Spending column  

---

## 📋 Data Quality Report
A structured Data Quality Report was created to document all data quality issues found in the dataset and the improvements made during the cleaning process. It focuses only on data cleaning issues such as missing values, duplicates, and formatting inconsistencies.
